# 手动控制：检出与载入图像

## 概览

教学程序（teach-imgui.exe）的缺陷检出页左侧面板里，紧跟相机通道分组之后是「手动控制」分组。它把"什么时候检出、检出哪张图"交给用户：默认仍是自动检出，勾选「手动模式」后改动只刷新测试图，按「检出」（F5）才学习并检出；「载入图像…」则把一张 PNG/JPEG/BMP/TIFF 文件当作测试图。

## 与角色、对位的关系

教学程序默认是操作员界面，本文的「手动控制」与「载入图像…」属于管理员的缺陷检出页。无论测试图来自实时联机、相机抓拍、载入的图像还是本地仿真，都要先在对位页确认 ROI：每张图会先对齐到设计网格再检出，未确认对位时检测被阻止。角色、页面与对位流程见 [ROLES.md](ROLES.md)。

## 手动模式

复选框「手动模式（改动后不自动检出）」默认关闭（即与以前一样自动检出）。打开后，换相机通道、改光照、改检出参数或换图都只刷新测试图并清除上一次的结果，既不学习区间也不检出；这样可以在调参过程中避免反复重算，也便于先摆好场景再一次性检出。

## 检出按钮（F5）

「检出」按钮（快捷键 F5）在两种模式下都可用：当该通道还没有学习过区间（或刚按过「重新学习区间」）时，它先用良品样本学习区间，然后检出当前测试图；已经学过就直接检出。手动模式下它是唯一的检出入口。

## 载入图像

「载入图像…」打开 Windows 的打开文件对话框（`GetOpenFileNameW`），可载入 PNG、JPEG、BMP 或 TIFF，统一转换成 8 位灰度图作为测试图。图像尺寸必须与当前型号一致，否则显示错误并保持原图。载入的图像会取代实时联机画面、相机抓拍与本地仿真，并停止「跟随相机工作室」；按「改用仿真」、重新 Snap / 载入抓拍或重新勾选跟随，都会把它换掉。分组下方显示当前图像是否已检出（「尚未检出，按「检出」(F5)。」或「已检出：N 个缺陷」）。

## 与其他图像来源的关系

载入的图像优先级最高：它一旦生效，实时联机、相机抓拍与本地仿真都不再提供测试图。标准图 / 差异图视图显示的就是这张测试图（载入的图像没有标准图）。检出本身依旧只接收测试图与设计材质图，与图像来自哪里无关。

## 学习区间

载入的图像没有良品样本，所以学习（每个通道的首次检出，或按「重新学习区间」）就用这张图自己学习区间。正确用法是：先载入一张良品图并检出一次，再载入待测图检出。

## 保存

「保存」在载入图像时只写出 `inspect.json`（检出参数），不写抓拍图像；抓拍图像由工作室或相机抓拍流程产生。

## 限制

- 一张载入的图像对三个相机通道共用，不会按通道分别载入。
- 彩色文件会被转换成灰度，颜色信息丢失。
- 图像尺寸必须与型号一致。
- 载入的图像没有标准图，标准图 / 差异图视图显示测试图。
- 文件对话框只在 Windows 上可用；其他平台点击按钮会提示"此平台没有文件对话框"。
