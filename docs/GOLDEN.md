# 金板（Golden Board）与检查区域

## 为什么需要金板

AFVI 的检查区域不是整个实物，而是金板上的遮罩（Mask）。对位（Align）的最终目的就是让遮罩和实物重叠：对位把每一张采集图搬到金板所在的网格上，之后由遮罩而不是设计层来决定检查哪里。

为了防止边缘过杀，遮罩要比实物略小一圈，这个留边叫 Padding，值很小，由用户输入。金板是用实物拍出来的假想图（二值遮罩），不是设计层画出来的想象图。

检出算法（internal/inspect）仍然只拿到 8 位灰度测试图和由遮罩生成的材质图（3 = 缩进后的 Metal，1 = SR，0 = 不检查），不知道任何模拟信息，材质图之外什么都不检查。

## 页面与角色

操作员页面顺序：对位 → 金板 → 检测。

管理员页面顺序：对位(roi) → 对位试验台(align) → 金板(golden) → 缺陷检出(defect)。

金板页对两种角色都可见。金板没有生成（还在后台构建）时检测被阻止；金板改动后没有「确定金板」时，检测页给出未保存提示。

## 金板页怎么读

- 默认只画**最终检查区域**：品红 = Metal 检查区（已经减去 Padding，所以比画出来的金属小一圈），绿色 = SR 检查区。颜色按钮的第一个就是品红（默认）。
- 「显示留边」画出画出来的金属里没有被检查的部分（Padding 去掉的一圈和 UserMask 挖掉的区域，蓝色），**默认关闭**；要看 Padding 到底去掉了哪里时再勾选。
- 添加 / 擦除时拖的框是白色虚线。
- Padding 比较大时，细的走线会只剩很细的一条甚至消失——这是 Padding 的效果，不是 bug。
- 制作金板整体上就是给 Metal 上色：把要检查的金属画进遮罩，Padding 与 UserMask 再往里收、再挖掉。

## 金板页上的控件

| 区域 | 控件 | 说明 |
|---|---|---|
| 图片 | 通道 R/G/B | 金板用该通道的良品样本图画 |
| 二值化范围 | 范围内 / 范围外，下限 GV，上限 GV（0..255） | 阈值得到 Metal 遮罩 |
| 添加 / 擦除 | 工具：鼠标点（只看像素信息）/ 添加 / 擦除；形状：矩形 / 椭圆 / 多边形（多边形：左键依次点顶点，右键闭合） | 「仅亮度 ≥ GV」：0 表示框内全部加入，设为 N 时框内只有灰度不小于 N 的像素被加入，配合画框更精准地纳入想要的亮区域（实机的添加做不到这一点） |
| 面积阈值 | 最小面积 px（2..5000）、「同时填补小孔洞」、应用 | 去掉过小的碎块，填补内部小孔洞 |
| 形态学 | Open 开（去掉突出的单个像素）、Close 闭（补齐缺失的单个像素）、Erode 腐蚀、Dilate 膨胀，次数 N（1..64），各自有「应用」 | 逐项应用 |
| 检查区域 | Padding 留边 px（0..64，默认 4）；SR 内缩 px（0..64，默认 4） | 决定实际检查的金属区域与 SR 区域 |
| 显示 | 遮罩颜色（第一个是品红，默认）、不透明度 %、显示检查区域（金属=品红、SR=绿色，默认只画这个）、显示留边（Padding 去掉的一圈，蓝色，默认关闭） | 仅影响显示 |
| 按钮 | 撤销（也可在视图上按 Ctrl+Z，历史 6 步，只记遮罩和范围，不记 Padding / SR 内缩）、自动生成、确定金板（保存）、载入 | 金板建好后还有大按钮「下一步：检测」 |

## 检查区域怎么得到

- Metal 检查区 = 金属遮罩向内收 Padding 个像素（方形结构元，切比雪夫距离）。
- 留边 = 金属遮罩减去检查区（不检查，可显示）。
- SR 遮罩自动生成（绿色），= 设计 SR 层在图上的位置（见下一节）向内收 SR 内缩 个像素，并且与金属遮罩保持同样的距离（金属遮罩膨胀同样的像素后从 SR 中扣掉）。
- 材质图：Metal=3、SR=1、其余 0。
- UserMask（不检查区域）：管理员在「缺陷检出」页画的排除区域，Metal 区域只从 Metal 检查区扣除、SR 区域只从 SR 检查区扣除（见下一节）。最终检查区域 = 金板遮罩 − Padding − UserMask。

用金板时检出参数的「边缘留边 EdgeMargin」默认 0，因为留边已经由 Padding 完成；没有金板（旧流程）仍然是 6。

## UserMask（不检查区域）

名称在三种语言里都是 UserMask。管理员在「缺陷检出」页左栏的 UserMask 区域编辑：类别（Metal 或 SR）跟随缺陷页上方的子选项卡（Metal | SR），点形状按钮（矩形 / 椭圆 / 多边形）打开或关闭对应的画框工具，在图上拖框（多边形左键依次点顶点、右键闭合）。

- 每个区域只从自己那一类检查区域里扣除：Metal 区域只扣 Metal 检查像素，SR 区域只扣 SR 检查像素。可以放心画大一点，画到另一种材质上也不影响它。
- 列表里可逐个删除，也可按类别或全部清空；最多 256 个区域。
- 区域坐标是设计网格坐标（对位完成后的图）。
- 改 UserMask 不会重新对位，也不会清掉调好的检出区间（金属遮罩、Padding、SR 内缩变了才会重新学习）。
- 检出参数里「边缘留白」（EdgeMargin）大于 0 时，被扣掉的区域边缘也会按该值留白。
- 整张图都被扣光时检测被阻止（和空金板一样）。
- 角色：只有管理员的「缺陷检出」页能编辑；操作员页面只受其影响，检测结果里不会出现这些区域。

## 自动生成与设计层配准

第一次载入模型时自动生成：

1. 用设计 TIFF 层（Metal / SR / Open）对良品样本图做一次整体配准（`core.DesignTemplate`），把设计材质图用 `core.WarpMaterialToReference` 搬到图上。
2. 用 Metal 与 SR 两个区域的灰度自动求二值化范围（`golden.AutoRange`，Metal 亮于 SR 时为「下限..255」范围内，否则为「0..上限」），再做一次 Open 1。
3. 范围求不出来（平坦通道、空类）时退回设计 Metal 层并提示。

SR 层再按图贴边（`goldenSnapSR`）：只保留图上看起来像 SR 的像素（SR 内部灰度均值 ± max(4σ, 6)，开运算 1、去掉小于 64 像素的碎块），**只会缩小不会扩大**，图与层相差太大（保留不到 70%）时退回原层。

原因：设计层和真实图相差 2-6 个像素，不贴边时 SR 边缘会被误检。

## 对位模板跟着金板走

对位的模板不再是设计层画出来的想象图，而是用金板的类别图画出来（`core.PaintedTemplate`：金属=drawn Metal、SR、Open、其余为底，面积下采样后模糊，不再单独配准），这样对位后的采集图正好落在遮罩上。

金板改动（Rev 变化）后检测会自动重新对位、重新学习区间。

实测：用设计层模板时对位后与金板遮罩仍有约 8 像素错位，改用金板模板后残差 ≤ 1-2 像素。

## 保存与载入

文件夹 `captures/<模型号>/golden/`（`AFVI_CAPTURES` 可改根目录），包含：

- `golden.json`：设置、范围、Padding、SR 内缩、通道，以及 `userMask`（UserMask 区域；没有区域时不写这个键，所以不含区域的旧金板文件逐字节不变，版本号仍是 1）；
- `golden-metal.png`：遮罩，sha256 校验。

`userMask` 数组的每一项：

```json
"userMask": [
  {"target": "metal", "kind": "rect",    "p0": [x, y], "p1": [x, y]},
  {"target": "sr",    "kind": "ellipse", "p0": [x, y], "p1": [x, y]},
  {"target": "metal", "kind": "polygon", "points": [[x, y], [x, y], [x, y]]}
]
```

`target` 是 `metal` | `sr`，`kind` 是 `rect` | `ellipse` | `polygon`；`p0`/`p1` 是矩形/椭圆的对角两点，`points` 是多边形顶点，都是设计网格坐标。载入时未知 target / kind、无效区域或超过 256 个都会报错；键缺失时 UserMask 为空。

「确定金板」保存；载入时模型号和尺寸必须一致，否则拒绝。

## 默认值怎么定的（参考模型 FM1/25fbo015-15 实测）

条件：无缺陷良品图，整图 5860×4020。

| Padding | 误检数 (Metal) |
|---|---|
| 2 | 101 |
| 3 | 12 |
| 4 | 0 |
| 5 | 0 |

| SR 内缩 | 误检数（不贴边） | 误检数（贴边） |
|---|---|---|
| 1 | 137 | — |
| 2 | 122 | 0 |
| 3 | 101 | 0 |
| 4 | 13 | 0 |
| 5 | 1 | — |
| 6 | 1 | — |

（Padding 固定 4；贴边列只测过 2、3、4。）

结论：默认 Padding 4、SR 内缩 4 时良品 0 个误检，10 个默认小缺陷全部检出、无多余。对位后与金板的整图残余错位：最大 1.48 px、均方根 0.92 px。

这些值只是该参考模型上的默认，现场按实际情况调整（Padding 往往只需很小）。

## 常见问题

- **为什么我加的区域看不见 / 很细**：Padding 会把金属遮罩向内收一圈，细走线可能只剩很细的一条甚至整条消失，这是 Padding 的效果，不是 bug。勾选「显示留边」可以看 Padding 到底去掉了哪里，或把 Padding 调小。
- **画了 UserMask 好像没效果**：确认缺陷页上方的子选项卡选的是想扣的那一类（Metal 子选项卡只扣 Metal 检查像素、SR 子选项卡只扣 SR 检查像素），且金板已生成——后台构建完成前页面不显示检查区域，检测也被阻止。

## 自检与测试

`internal/golden` 是只依赖标准库的纯 Go 包（`internal/inspect`、`internal/core` 不会引用它，有隔离测试）。

纯 Go 测试：`go test ./internal/golden/...`。

窗口自检（`teach-imgui.exe -selftest`）的金板步骤：

- golden-attach、-range、-morph、-undo、-padding、-padding-zero、-srinset
- -add-rect、-erase-ellipse、-add-polygon、-add-mingv、-area
- -save、-load、-i18n-en、-i18n-ko、-inspect
- golden-e2e-good（对位后的良品图 0 个缺陷）
- golden-e2e-defects（10 个默认小缺陷检出至少 7 个，多余不超过 6 个）
- 操作员步骤 roles-golden
